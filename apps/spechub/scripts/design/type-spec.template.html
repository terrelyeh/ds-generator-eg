02字級尺標

四種版型用到的所有級數，依真實 pt 大小由大到小排列。這是這頁最實用的一張表 —— 直接看得出 24pt 標題和 7pt 規格字的實際落差。

__LADDER__
螢幕上的「真實大小」有前提。CSS 的 pt 換算成 96dpi 下的 px（1pt = 1.333px）， 在瀏覽器 100% 縮放時等同 PDF 的實際級數。若你的螢幕有系統縮放，物理尺寸會跟著變 —— 要精準對照請以 pt 數值為準，或把 PDF 用 100% 開起來並排。

03版型 A · 標準（Cloud 骨架）

拉丁文（en / es）

Manrope + Roboto body 基準 7pt · 主題色隨配色變動

級數與字重可以在 Settings ▸ Typography 直接調整，不用改程式 —— 但字體不行：那裡設定的是內文字體，標題一律 Manrope（品牌規範，寫死在元件裡）。 西班牙文刻意沿用英文級數 —— 封面長度是靠翻譯提示裡的「行數對齊」控制，不是靠縮字。

__TBL_A__
角色級數字重行高顏色實際大小

CJK（ja / zh-TW）

Zen Kaku Gothic New · Noto Sans TC 行高與內文色由「文字系統」決定，不隨語系開放調整
__TBL_CJK__
角色日文 ja繁中 zh-TW行高備註
為什麼行高不開放調。行高、內文色與頁尾樣式跟著文字系統走，不是跟著語系走： CJK 需要比拉丁更鬆的行距和更深的內文色。如果做成可依語系設定，就有人能把西班牙文設成 CJK 行距， 而那正是封面破版最常見的成因。

09改字級要去哪裡改

版型語系可調位置

B Data Center全部寫死在 datacenter-preview.tsx，需改程式
C Broadband全部寫死在 broadband-preview.tsx，需改程式

Typography 設定頁不提供行高與內文色。那兩項跟著文字系統走（拉丁 / CJK）， 由算繪端依語系判斷後套用，避免有人替拉丁語系套上 CJK 行距而造成封面破版。
